## vi
### Cải thiện
- **Thêm repo GitHub mới ngay ở project, trợ lý và hộp tạo team.** Danh sách chọn repo ở ba chỗ này nay có dòng "+ Thêm repository trên GitHub" như trong hội thoại. Cấp thêm repo trên GitHub xong quay lại là danh sách tự hiện repo mới, không cần tải lại trang.

## en
### Improved
- **Add new GitHub repos right from a project, an assistant or the create-team box.** The repo picker in those three places now has the "+ Add repositories on GitHub" row, as in the chat. Grant more repos on GitHub, come back, and the list shows them without a reload.
